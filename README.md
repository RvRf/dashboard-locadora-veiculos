 Análise de Dados - Locadora de Veículos

 Contexto
Projeto desenvolvido para fins de estudo e prática em análise de dados, utilizando Power BI e Excel.

 Objetivo
Analisar dados de uma locadora de veículos para identificar padrões de faturamento, utilização da frota e desempenho operacional.

 Ferramentas Utilizadas
- Power BI
- Microsoft Excel

 KPIs
- Faturamento total
- Total de clientes atendidos
- Utilização média dos veículos (KM rodado)
- Média salarial dos funcionários para análise de custos operacionais

 Análises Realizadas
- Comparação de faturamento por período
- Análise de desempenho por categoria de veículo
- Identificação de dias de maior demanda
- Avaliação da ocupação da frota
